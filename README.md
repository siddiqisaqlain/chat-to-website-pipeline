# Chat to Website Pipeline

Outreach tracker for selling the WhatsApp-to-website service: daily DM and walk-in counts, a niche test (reply, demo, visit, pilot and paid rates per niche), every shop's stage, and Hinglish sales scripts.

Open it: https://siddiqisaqlain.github.io/chat-to-website-pipeline/

Your shop list is saved in the browser of the device you use (nothing is sent anywhere). Use **Export backup** to keep a copy or move it to another device, and **Import backup** to load it.
